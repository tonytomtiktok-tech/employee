# Workflow

```
NOT_STARTED → SELF_DRAFT → SELF_SUBMITTED → MANAGER_DRAFT → MANAGER_SUBMITTED
→ COMMITTEE_IN_REVIEW → FINALIZED → PUBLISHED
```

Controlled: RETURNED_TO_SELF, RETURNED_TO_MANAGER, CANCELLED, REOPENED_BY_HR (reason + audit required).

Rules: manager cannot submit before self; committee cannot finalize before manager; executives see PUBLISHED by default.
